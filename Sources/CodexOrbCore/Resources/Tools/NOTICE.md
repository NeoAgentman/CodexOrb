# Bundled CLI provenance

OpenToken 0.3.28 is the only bundled executable. It was imported from the owner's
installed CLI on 2026-09-09, with arm64 and x86_64 slices. Redistribution terms
remain unverified; inclusion was explicitly requested by the repository owner.
No credentials, logs or service definitions are bundled.

CodexOrb discovers an external Codex runtime and checks its app-server schema.
It does not bundle or update Codex. CodexBar is no longer included.
OpenToken updates run on an isolated temporary copy and retain previous versions.
SHA256SUMS pins source resources; packaging signs executable copies.
